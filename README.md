# GSVR Companion

Play Counter-Strike 1.6 (and later other Half-Life mods) maps, weapons and bots in VRChat — built locally from **your own** installed copy of the game.

**Download & instructions:** https://devilblader87.github.io/gsvr-companion/

* Releases: see the [Releases](https://github.com/Devilblader87/gsvr-companion/releases) page. The companion updates itself from here.
* The VRChat world contains no game files. The companion converts maps / models / sounds from your install on your PC and serves them to VRChat on `127.0.0.1` only.
* PC (Windows) VRChat only. Needs the VRChat setting *Allow Untrusted URLs*.
