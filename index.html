GSVR Companion

Play Counter-Strike 1.6, the Half-Life campaign, Sven Co-op and Warcraft III in VRChat — built from your own installed games, on your PC.

Four separate worlds: GSVR - Counter-Strike (classic rounds, bomb, hostages, bots), GSVR - Half-Life (the campaign in co-op: HL weapons, HEV, monsters), GSVR - Sven Co-op (co-op maps with Sven weapons, monsters and allies) and Warcraft III (melee, tower defense and other custom maps on a table — box-select with the trigger, right click with the grip — with your friends). Each world only needs the game it is built from.

Get playing in 3 steps

  1. Install the game you want to play on this PC: Counter-Strike 1.6, Half-Life and/or Sven Co-op (Steam is found by itself; an install without Steam or in another folder can be chosen in the settings: Half-Life / Counter-Strike Ordner), or Warcraft III (classic 1.21 – 1.31). The Spiele tab of the companion shows where each game was found and lets you change the folder.
  2. Run GSVR-Setup.exe — no admin rights needed, it starts with Windows and updates itself.
    Windows may say “Windows protected your PC” (new, unsigned app): click More info → Run anyway.
  3. In VRChat: Settings → Comfort & Safety → Allow Untrusted URLs: on. Join the world — the lobby shows a green light when everything is ready, then pick a team.

Why a companion app?

The world does not contain any game files. The companion reads maps, models and sounds from the copy of the game that you own, converts them on your PC and hands them to VRChat over 127.0.0.1 (your own computer only). Only games you have installed can be played; game data never leaves your PC.

Warcraft III: sharing fan maps

Like in the original game, the host can play a custom map that a friend does not have: the friend's companion downloads only the map file through the GSVR relay (w3relay.heimserver.me, files are kept 24 h and can only be fetched by their exact hash) and builds the map from the friend's own Warcraft III. The map keeps its name and is saved in Warcraft III\Maps\Download\GSVR, so it also works in the real game. Blizzard's own maps and game data are never sent. You can switch it off in the settings (Karten vom Host automatisch laden: on / ask / off). Takedown requests: abuse@heimserver.me.

Trouble?

  • "Companion not found" — the app is not running, or a firewall blocks local connections.
  • "Untrusted URLs" — switch the VRChat setting above on and rejoin.
  • "Game not installed" — install it in Steam (the companion rescans automatically) or choose the game folder in the settings.
  • "Map not in your install" (Warcraft III) — the host's map could not be fetched: check that map sharing is on, or copy the map into your Maps folder.
  • VRChat on PC (Windows) only — Quest / Android cannot load local files.
