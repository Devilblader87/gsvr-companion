日本語

自分のPCにインストールした Half-Life、Counter-Strike 1.6、Sven Co-op、Warcraft III、ROSE Online を VRChat で遊べるツールです(ゲームは各自でご用意ください)。

  1. 上のボタンから GSVR-Setup.exe をダウンロードしてインストールします。
  2. コンパニオンを起動すると、ゲームが自動で検出されます。「スタート」を押すと準備が始まります。
  3. VRChat の設定 → Comfort & Safety → 「Allow Untrusted URLs(信頼されていないURL)」をオンにします。
  4. 「VRChatでワールドを開く」を押して参加します。

Windows PC の VRChat のみ対応です。質問・不具合報告は Discord へ。

Get playing in 4 steps

  1. Run GSVR-Setup.exe — no admin rights needed, it starts with Windows and updates itself.
    Windows may say “Windows protected your PC” (new, unsigned app): click More info → Run anyway.
  2. Start the companion. Your installed games are found automatically; press Start (1-click setup) to build what is needed. The Simple view shows each world's status. A game that is not found can be set in the Games tab (Advanced view).
  3. In VRChat: Settings → Comfort & Safety → Allow Untrusted URLs: on.
  4. Press Open world in VRChat (or use a link below) and join.

VRChat on PC (Windows) only — Quest / Android cannot load local files. The companion is available in English, Japanese and German.

Worlds

  • GSVR - Half-Life — campaign and mod hub (Opposing Force, Blue Shift, Ricochet, DMC, Sven Co-op). Needs Half-Life (+ mods / Sven Co-op).
  • GSVR - Counter-Strike — needs Counter-Strike 1.6.
  • Warcraft III — melee, tower defense and other custom maps on a table. Needs Warcraft III 1.21 – 1.31.
  • GSVR - ROSE Online ローズオンライン — needs ROSE Online.

All worlds are alpha. Each world only needs the game it is built from; a banner at its spawn shows the current status and changes.

Why a companion app?

The worlds contain no game files. The companion reads maps, models and sounds from the copy of the game that you own, converts them on your PC and hands them to VRChat over 127.0.0.1 (your own computer only). Nothing is downloaded and game data never leaves your PC.

ROSE Online (alpha)

The install is found automatically (registry, Steam, usual folders); otherwise set the "ROSE Online folder" in the Games tab or start with --rose-install <folder>. On first join the zone, avatar and lobby packs are built from your own install, about 1 minute per zone, in the background (progress is shown in the world's load room) and cached. Zone loads in the world can still take 1.5 to 2.5 minutes; neighbour zones are preloaded.

Zones (0.9.49): Birth Island, Valley of Luxem Tower, Adventurer's Plain, Breezy Hills, Canyon City of Zant, El Verloon Desert, Anima Lake, Forest of Wisdom, Kenji Beach, Gorge of Silence, Goblin Cave (B1-B3), Junon Polis, Dolphin Island, Junon Clan Field, clan hideout; Luna: Magic City of Eucar, Mana Snowfields, Arumic Valley, Crystal Snowfields, Freezing Plateau, Luna Clan Field; Eldeon: Refuge Xita, Shady Jungle.

Co-op up to 4, parties (with party voice), clans and a global chat. Original skill effects, skill tooltips, 3 x 30 bag, second job change, level cap 250, bows/guns use ammo, all NPCs and most quests run.

Warcraft III: sharing fan maps

If the host plays a fan map a friend does not have, the friend's companion fetches only that map file through the GSVR relay (w3relay.heimserver.me; files are kept 24 h and can only be fetched by their exact hash) and builds it from the friend's own Warcraft III. The map is saved in Warcraft III\Maps\Download\GSVR, so it also works in the real game. Blizzard's own maps and game data are never sent. Switch it off in the settings (Load maps from host automatically: on / ask / off). Takedown requests: abuse@heimserver.me.

Troubleshooting

  • The world says the companion is missing: start the companion and make sure Allow Untrusted URLs is on in VRChat.
  • A game is not found: set its folder in the Games tab (Advanced view); it shows where each game was found (Steam, registry, folder scan or by hand).
  • The first load is slow: the first build converts your game data and is cached; later loads are much faster. ROSE builds in the background, about 1 minute per zone.
  • The menu is hard to click in VR: set VRChat's Forced Camera Near Distance to None.
  • A Warcraft III map behaves like before an update: update the companion; a new version rebuilds the maps by itself the next time they are played.
  • No update banner on 0.9.49 / 0.9.49.1: switch to the Advanced view once (button at the top); the yellow "Update available" bar appears there. Later versions show updates in both views and update automatically.

The full version history is in the changelog. On Linux / Steam Deck the Windows build runs under Proton; see the README.
